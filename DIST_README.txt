================================================================================
                        TWX Parser - Executable Version
================================================================================

HOW TO RUN:
-----------
Simply double-click "twx-parser.exe" to start the application.

A console window will open showing:
  - Server startup messages
  - The URL (usually http://localhost:3000)
  - Status messages

Your default web browser will open automatically with the TWX Parser interface.


IMPORTANT:
----------
1. DO NOT close the console window while using the application!
   The console window must stay open for the web interface to work.

2. Keep all files together!
   The following files must be in the same folder as twx-parser.exe:
   - twx-viewer-new.html
   - twx-viewer-new.css
   - twx-viewer-new.js
   - twx-viewer.html
   - .eslintrc.cjs
   - node_modules folder (with ESLint and dependencies)
   - output folder (for storing analysis results)


TO STOP THE APPLICATION:
-------------------------
Press Ctrl+C in the console window, or simply close the console window.


TROUBLESHOOTING:
----------------
If the application doesn't start:

1. Check the console window for error messages
2. Make sure all files are in the same folder
3. Make sure the "output" folder exists
4. Make sure the "node_modules" folder exists with ESLint
5. Try running as Administrator (right-click > Run as Administrator)


SYSTEM REQUIREMENTS:
--------------------
- Windows 7 or later
- 100 MB free disk space
- Internet browser (Chrome, Firefox, Edge, etc.)


FEATURES:
---------
- Parse and analyze IBM BPM TWX files
- Static code analysis with ESLint
- Interactive web interface
- Search and filter capabilities
- Export analysis results
