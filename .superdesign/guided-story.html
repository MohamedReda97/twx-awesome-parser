The Purpose

Local-First BAW Analysis

TWX Parser transforms opaque IBM Business Automation Workflow archives into navigable, structured intelligence. Built for enterprise data privacy, it runs entirely on the local machine with zero database dependencies.

No-Database Model

State is derived directly from ZIP contents and persisted as high-performance JSON files in a flat output structure.

Unified Context

Resolves dependencies across the main application and multiple nested toolkit context levels for accurate cross-object lookup.
