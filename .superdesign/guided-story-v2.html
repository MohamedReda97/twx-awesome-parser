The Goal

From opaque IBM BAW archive to navigable architecture

TWX Parser processes IBM Business Automation Workflow archives to extract actionable findings. Designed for privacy and auditability, it runs entirely on local machines using standard file system persistence.

Local Execution

No database dependencies or external services. State is derived from ZIP contents and stored in flat JSON structures.

Unified Scope

Resolves declarations across both main application and nested toolkit context levels for accurate static analysis.

Findings Hierarchy

Rules are categorized by status and severity, providing evidence including exact line, column, and snippet.

Critical Execution-Stopping Failures
JavaScript Syntax Error

Acorn fails to parse the script; deployment will fail.

Definite Null/Undefined Access

Proof of member access on null or undefined literals.

Unsafe Dynamic Execution

Direct tw.local input reaching eval() calls.

Also: Undefined Identifier, Definite Division by Zero
Warning High-Risk Logic Patterns
Undeclared Process Variable

Access to tw.local.x where x is not in the object's variable map.

Loop With No Demonstrable Exit

Infinite loop detection for while(true) without break/return.

Also: Debugger Statement, parseInt Missing Radix
Review Security & Quality Observations
Dynamic SQL Construction

Concatenation used in variables appearing to be queries.

Embedded Secret

Literal string values assigned to 'password' or 'apiKey' named variables.

Also: Empty Catch, Hardcoded Business Constant
