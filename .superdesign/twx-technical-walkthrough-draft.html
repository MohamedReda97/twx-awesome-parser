CHAPTER 02

Abstract Syntax Tree (AST) Generation

Our AST structure is minimized for serialization, prioritizing traversal speed over metadata density.

ast_engine.twx
interface Node {
  type: NodeType;
  start: number;
  end: number;
  body?: Expression | Statement;
}

export class TWXParser extends BaseParser {
  parseProgram(): Program {
    const node = this.startNode();
    node.body = this.parseBlock();
    return this.finishNode(node, "Program");
  }
}
